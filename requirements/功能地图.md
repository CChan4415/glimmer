# 功能地图：Glimmer / 流萤

> 状态：需求整理中（基于 2026-06-24 对话总结）
> 背景来源：[context/软件idea_对话总结.md](../context/软件idea_对话总结.md)

## 0. 命名（当前状态）

- 英文名：**Glimmer**（选定）——忽明忽暗的光，呼应"展示关系的存在，而不暴露关系的身份"
- 中文名：**流萤**（选定）——萤火虫的光：每个人都是夜空里发光的萤火，彼此照亮、互相发现
- 备选中文名：熹微（晨光熹微，文学感）、微芒（微小的光芒）
- 待办：商标 / 域名 / 应用商店查重（Glimmer / 流萤 均需确认可用性）

## 1. 产品定位（一句话）

发现你身边隐藏的关系机会——"展示关系的存在，而不暴露关系的身份"。

本质是半熟人社交 / 关系发现引擎（Relationship Discovery Engine），不是聊天工具，不是陌生人社交。

## 2. 功能地图总览（按用户旅程）

### 2.1 登录 / 注册（P0）

- 登录方式：Apple ID / Google / 邮箱（不用手机号，降低"又一个社交软件"的压迫感）
- 首屏文案："欢迎来到你的关系空间，这里只有你能看见你的关系图谱"
- 展示隐私承诺：默认匿名、关系图仅自己可见
- 待定：若进入中国市场，需增补手机号 / 微信登录方案

### 2.2 首次使用：建立关系网（P0）

- 手动添加联系人：姓名、关系类型（同学 / 同事 / 家人 / 兴趣同好）、认识时间、兴趣标签
- 录入约 10 人后立即展示价值统计（核心关系 / 工作关系 / 兴趣关系）
- P1：导入通讯录自动补全（先手动、后导入，降低敏感度）
- P1：AI 自动打标签

### 2.3 首页：今日关系机会（P0）

首页不放关系图（关系图放第二层），放"今日关系机会"：

- 提醒：你已经 180 天没联系张三（你最强的产品资源）
- 动态：你的人脉中新增 3 位 AI 创业者
- 位置：最近 2 位朋友来到新加坡
- 距离：你和某投资人之间只差 2 层关系

### 2.4 关系管理（P1）

- 联系人列表 / 详情：认识时间、最近联系、标签、关系强度
- 关系圈层：核心圈 / 工作圈 / 兴趣圈 / 失联圈
- 关系资产统计：创业者 N 人、程序员 N 人、投资人 N 人……

### 2.5 关系发现（P0）

- 按兴趣 / 角色 / 需求搜索（"我想认识摄影爱好者"）
- 结果按关系距离展示：1 度 N 人 / 2 度 N 人 / 3 度 N 人
- 隐私：只显示"某律师 / 某VC / 某工程师"，不显示姓名；授权后才解锁

### 2.6 引荐请求（P0）

- 发起：点击"介绍给我"
- 流转：中间人收到"XX 想认识你的 XX 朋友"→ 同意 / 拒绝
- 结果：同意后建立连接；拒绝时请求方不知道对方是谁

### 2.7 关系图谱（P1，第二层入口）

- 可视化自己的人际网络
- 支持按圈层 / 标签筛选

### 2.8 AI 关系顾问（P1 → P2）

- 每日推送：应该联系谁、错过了谁、谁可能帮助你
- 自然语言问答："我准备创业，应该联系谁？" → 推荐王五（连续创业者）、Tony（融资经验）等
- 关系资产分析：最有影响力节点、最容易帮你找工作 / 融资的人

### 2.9 机会市场（P2，未来）

- 发布需求（找律师 / 联合创始人 / AI 工程师 / 投资人）
- 优先从人际网匹配，而非全网搜索
- 成功对接后可收费（关系服务）

### 2.10 会员与商业化（P2）

- 免费版：每月 10 次关系搜索
- Pro 版：无限搜索 + AI 分析 + 高级引荐（$9.99 / 月）
- 关系服务费：找人成功后收费

## 3. MVP 范围（第一版只做）

1. 登录 / 注册
2. 建立关系图（手动添加联系人 + 兴趣标签）
3. 关系发现（按距离展示匿名结果）
4. 引荐请求

明确不做：聊天、发动态、朋友圈、点赞。

## 4. 贯穿性需求（所有模块）

- 隐私：默认匿名、四层可见性（私人 / 匿名共享 / 半公开 / 授权公开）
- 数据：关系数据仅用于本人使用 + 授权引荐；不公开他人身份
- 合规：隐私政策、数据导出 / 删除
