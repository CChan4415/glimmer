## 1. 导航结构

### 1.1 移动端 Tab 结构

```
┌─────────────────────────────────┐
│  Tab 1       Tab 2       Tab 3  │
│  关系图      联系人      我的    │
│                                 │
│         (页面内容区)             │
│                                 │
└─────────────────────────────────┘
```

| Tab | 名称 | 对应端点 | 核心功能 |
| --- | --- | --- | --- |
| Tab 1 | **关系图** | `GET /me/graph` + `GET /me/network/*` | 图展示、节点交互、2 度展开、资产统计 |
| Tab 2 | **联系人** | `GET /me/contacts` | 列表浏览、搜索（本地过滤，非服务端搜索）、编辑、手动添加 |
| Tab 3 | **我的** | `GET /me/privacy` `GET /me/account` | 隐私设置、账号管理、导入通讯录入口、数据导出/删除 |

### 1.2 关键入口的归属

| 功能 | 入口位置 | 说明 |
| --- | --- | --- |
| 导入通讯录 | 关系图 Tab（空态主按钮）+ 我的 Tab（设置区） | 首次引导在关系图空态 |
| 手动添加联系人 | 联系人 Tab（右上角 +） | 单个添加；批量表格在导入流程中 |
| 隐私设置 | 我的 Tab | `GET/PUT /me/privacy` |
| 账号管理 | 我的 Tab | 含数据导出、删除账号 |
| 关系图 | 关系图 Tab（默认首页） | 登录后进入的第一个界面 |

### 1.3 Web 端导航

```
┌──────────────────────────────────────────┐
│  Logo             关系图        用户头像  │
│                                       │
│           (全屏关系图画布)              │
│                                       │
└──────────────────────────────────────────┘
```

- Web 仅一个主界面：**全屏关系图** + 顶部导航。
- 无通讯录导入、无联系人列表 Tab、无隐私设置（或放顶部导航隐藏菜单）。
- Web 上的节点交互同 App（点开详情、展开 2 度），但不提供编辑/删除（放 App）。

**【需决策，见 D-1】**

## 3. 关键页面布局

### 3.1 登录页（P1）

```
┌──────────────────────────┐
│                          │
│      [App Logo]          │
│      流萤 / Glimmer      │
│                          │
│  发现你身边隐藏的关系机会  │
│                          │
│  ┌────────────────────┐  │
│  │ +86 │ 手机号       │  │
│  └────────────────────┘  │
│  ┌────────────────────┐  │
│  │   获取验证码        │  │
│  └────────────────────┘  │
│                          │
│  ── 或 ──               │
│                          │
│  [微信登录]  [Apple 登录]│
│                          │
│  登录即表示同意           │
│  《隐私政策》《用户协议》  │
└──────────────────────────┘
```

- 手机号输入框含 +86 国家码（默认中国，[可选其他国家代码，见 D-2]）。
- 微信/Apple 按钮为系统 OAuth 标准按钮（微信 SDK / Apple Sign-In 官方样式）。
- 底部《隐私政策》必须在登录前可点击查看全文。

### 3.2 引导页（P2）

3 屏可滑动引导（可跳过）：

| 屏 | 标题 | 副文案 | 图 |
| --- | --- | --- | --- |
| 1 | 看清你的关系资产 | 一键导入通讯录，生成你的专属关系图 | 图示意（占位） |
| 2 | 隐私，由你掌控 | 你的真名仅自己可见；别人看到的是化名 | 隐私示意（占位） |
| 3 | 发现隐藏的连接 | 看看你和朋友的朋友之间，有多近 | 2 度展开示意（占位） |

最后一屏："同意并开始"主按钮。

### 3.3 关系图（主界面，P3）

```
┌──────────────────────────┐
│ 关系图        [导入] [·] │  ← 顶部栏：标题 + 导入按钮 + 通知/更多
│                          │
│  ┌────────────────────┐  │
│  │ 家人 10 · 同事 52  │  │  ← 统计卡片（可折叠）
│  │ 朋友 60 · 未分组 6 │  │
│  └────────────────────┘  │
│                          │
│       ○ (同事)           │
│      /|\                 │
│     / | \                │  ← 力导向图（我 = 中心）
│    ○  ○  ○              │     节点颜色 = 分组色
│   (家)  (朋)  (未)      │
│    │                     │
│    ○ ← 虚线 = 2度        │
│   (朋)                   │
│                          │
│  [导入通讯录] (空态按钮)   │  ← 联系人 = 0 时显示
└──────────────────────────┘
```

**交互规则**：
- 中心节点 = "我"，固定位置（不参与力模拟）。
- 1 度节点 = 实线圈，分组着色；已注册联系人节点上显示小圆点标识。
- 2 度节点 = 虚线圈，显示化名；与 1 度的连线为虚线。
- 缩放：捏合/双击缩放；拖拽：平移画布。
- 空态（0 联系人）：插画 + "导入通讯录"主按钮 + "手动添加"次按钮。
- 右上角 [·] = 通知 + 引导邀请入口。
- **一键展开**：图顶部栏提供"展开全部 2 度"按钮——一次性展开所有已注册 1 度联系人的 2 度节点；也可逐节点单点展开（D-5）。

### 3.4 联系人详情卡片（P4，Botton Sheet）

```
┌──────────────────────────┐
│  (图区域变暗/模糊)        │
│                          │
├──────────────────────────┤  ← 底部弹出
│  张三                     │
│  ┌─────────────┐         │
│  │ 同事 · AI · 创业      │  ← 分组 + 标签
│  └─────────────┘         │
│                          │
│  手机：138****9001       │
│  最近联系：2026-06-15    │
│                          │
│  [编辑]  [查看TA的朋友→]  │  ← 已注册联系人显示后者
│  [删除联系人]             │
└──────────────────────────┘
```

- 1 度联系人：显示真实姓名 + 完整信息。
- 2 度联系人（点击图中 2 度节点）：仅显示化名 + 分组（若对方允许），无编辑/删除/手机号。
- "查看 TA 的朋友" → 展开 2 度列表（P5），仅当对方已注册且授权时出现。
- 卡片向下滑动或点空白区域关闭。

### 3.5 2 度列表（P5）

```
┌──────────────────────────┐
│ ← 张三的朋友    共 18 人  │  ← 顶部返回栏
│                          │
│ ┌──────────────────────┐ │
│ │ 陈同学               │ │
│ │ 朋友 · 共同好友 3 人  │ │  ← 已注册，可展开
│ │               [展开→]│ │
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ 王同学               │ │
│ │ 同事 · 共同好友 1 人  │ │  ← 已注册，可展开
│ │               [展开→]│ │
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ 新朋友               │ │
│ │ 未注册               │ │  ← 未注册，不可展开
│ └──────────────────────┘ │
│ ...                      │
└──────────────────────────┘
```

- 列表中 2 度人物的分组仅当其设置 display_level=with_group 时显示。
- 共同好友数 = 我通过哪些 1 度也能触达此人（体现冗余关系）。
- 已注册 → 可继续展开（再点进入 2 度人物的 2 度 = 3 度——**第一版不做 3 度，点击无反应**[或显示引导"即将推出"，见 D-3]）。

### 3.6 联系人列表（P6）

```
┌──────────────────────────┐
│ 联系人          [+]      │  ← 右上角手动添加
│ ┌──────────────────────┐ │
│ │ 🔍 搜索联系人...     │ │  ← 本地过滤（非服务端搜索）
│ └──────────────────────┘ │
│ [全部] [家人] [同事] [朋友] [未分组] │ ← 分组 Tab
│                          │
│ ┌──────────────────────┐ │
│ │ 张三                 │ │
│ │ 同事 · AI, 创业      │ │  → 点击进入详情
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ 李四                 │ │
│ │ 朋友 · 骑行, 摄影    │ │
│ └──────────────────────┘ │
│ ...                      │
└──────────────────────────┘
```

- 搜索框为本地过滤（已在列表中的数据），不调服务端搜索 API。
- 分组 Tab 联动 `GET /me/contacts?group=xxx`。
- 列表项左侧可显示分组色小圆点。

### 3.7 导入通讯录流程（P9）

```
Step 1: 权限说明弹层          Step 2: 系统权限               Step 3: 完成页
┌──────────────────┐        ┌──────────────────┐        ┌──────────────────┐
│                  │        │                  │        │  导入完成！       │
│  导入通讯录      │        │  "Glimmer 想要   │        │                  │
│                  │        │   访问你的通讯录" │        │  共导入 128 人    │
│  用于生成关系图  │  →     │                  │  →     │  家人  10         │
│  你的手机号不会  │        │  [不允许] [允许]  │        │  同事  52         │
│  以明文存入云端  │        │                  │        │  朋友  60         │
│                  │        │                  │        │  未分组 6         │
│  联系人被朋友看  │        │                  │        │                  │
│  到时使用化名    │        │                  │        │ [生成我的关系图]  │
│                  │        │                  │        │                  │
│  [跳过]  [同意]  │        │                  │        │                  │
└──────────────────┘        └──────────────────┘        └──────────────────┘
```

- Step 1 拒绝 → 进入关系图空态（不卡流程），提供手动添加入口。
- Step 3 "生成我的关系图" → 跳转到 Tab 1（关系图），图已自动生成。

## 4. 导航流程

### 4.1 首次使用流程

```
App 冷启动
    │
    ▼
登录页 (P1) ──微信/Apple──→ 授权页面 ──→ 引导页 (P2)
    │                                        │
    └──手机号──→ 验证码 ──→ 引导页 (P2)      │
                                 │            │
                    ┌────────────┘            │
                    ▼                         │
              引导页 (P2) ──跳过──→ 关系图空态 │
                    │                         │
                    └──完成──→ 关系图空态      │
                                 │            │
                    ┌────────────┘            │
                    ▼
            关系图空态 (P3)
                    │
            ┌───────┴───────┐
            ▼               ▼
      导入通讯录 (P9)   手动添加 (P8/P10)
            │               │
            └───────┬───────┘
                    ▼
           关系图（含数据）(P3)
```

### 4.2 日常使用流程

```
Tab 1 关系图 ←──→ Tab 2 联系人 ←──→ Tab 3 我的
     │                  │                  │
     ├─ 点节点          ├─ 搜/筛列表       ├─ 隐私设置
     │  └─ 详情卡片     ├─ 点进详情        ├─ 账号管理
     │      ├─ 编辑     │  └─ 编辑/删除    ├─ 导入通讯录
     │      └─ 看TA朋友  │                  └─ 数据导出/删除
     │          └─ 2度列表
     │
     └─ 统计卡片
```
