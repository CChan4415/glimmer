## 1. 技术栈决策（T1-T7）

### T1：Flutter 状态管理 → Riverpod

- **决定**：**Riverpod**（flutter_riverpod + riverpod_annotation 代码生成）
- **理由**：轻量、Dart 风格自然、适合 3 Tab 小 App；Bloc 对此规模过重。
- **包**：`flutter_riverpod`、`riverpod_annotation`、`riverpod_generator`

### T2：SMS 服务商 → 阿里云短信服务

- **决定**：**阿里云短信服务**（国内 +86 送达率最高）
- **单价**：0.045 元/条（国内短信）
- **用途**：注册/登录验证码
- **包**：`dysmsapi20170525`（阿里云 Python SDK）或直接 HTTP API 调用

### T3：数据库 → Supabase Cloud 免费层

- **决定**：**Supabase Cloud 免费层**起步，后续按需升级
- **免费层额度**：500MB 数据库、5GB 带宽/月、50,000 月活用户、1 个项目
- **购买**：supabase.com → Sign Up → Create Project（选 `ap-southeast-1` 新加坡区，离大陆最近）
- **升级路径**：Pro 计划 $25/月（8GB 数据库、50GB 带宽）；或迁阿里云 PG（当需大陆低延迟时）
- **注意**：免费层项目 7 天无活动自动暂停（需在设置中关闭此选项，或定期访问）

### T4：Web 前端 → React + 图库

- **决定**：**React + d3-force / Cytoscape.js**（不选 Flutter Web）
- **理由**：Web 定位是"精美看图"，React 生态图库成熟；双端代码分叉可接受——Web 仅看图，功能远少于移动端
- **具体选型**（见 §3 渲染层选型）：
  - 力导向图渲染：**Cytoscape.js**（首选，功能完整、文档好、中等规模性能好）或 **d3-force**（更底层、更灵活但代码量大）
- **包**：React 18+、Cytoscape.js + cytoscape-dagre（分层布局备用）、React Router

### T5：对象存储 → 阿里云 OSS

- **决定**：**阿里云 OSS**（与 T2 SMS 同厂商，大陆访问最快）
- **计价**：存储 0.12 元/GB/月 + 外网流出 0.5 元/GB（第一版用量极小，约 1-2 元/月）
- **用途**：数据导出 CSV 临时文件、用户头像（可选）

### T6：CI/CD → GitHub Actions

- **决定**：**GitHub Actions**（免费，与仓库同厂商）
- **范围**：lint + test（pytest + Flutter test）；部署手动或半自动
- **不接自动部署**：第一版单人开发，手动 `git push + railway up` 更灵活

### T7：后端部署 → Railway（与 T3 捆绑）

- **决定**：**Railway**（railway.app），与 Supabase 同区域选 `ap-southeast-1`（新加坡）
- **捆绑理由**：后端 + 数据库在同一区域 → 内网延迟 <5ms；两者一起迁（如后续迁阿里云）
- **计价**：Railway 免费层含 $5 信用/月；第一版单实例可控制在费用内
- **升级路径**：Pro $20/月（更多资源）；若迁阿里云 → ECS + PG 一步到位

### 3.1 移动端

| 库 | 适用 | 选择 |

### 3.2 Web 端

| 库 | 节点上限 | 交互 | 选择 |

## 5. 风险与对策

### 5.1 微信登录的企业资质要求（关键风险）

- **问题**：微信开放平台移动应用需要企业认证（¥300/年），个人开发者无法创建移动应用的微信登录。
- **影响**：如果暂时没有注册公司，微信登录在第一版无法实现。
- **对策（三选一，见决策 D-2）**：
  - **A. 第一版放弃微信登录**——仅手机号 + Apple 登录。最简单，但少一个国内高频入口。
  - **B. 注册个体工商户**——成本低（几十元，部分城市线上办理），可以完成微信开放平台认证。
  - **C. 先做测试版，不上应用商店**——用 TestFlight + 直接 APK 分发，微信登录可以先接网页应用或小程序方案。

### 5.2 Supabase Cloud 中国大陆访问延迟

- **问题**：Supabase Cloud 服务器在新加坡，大陆用户 API 请求可能 100-300ms 延迟。PostgreSQL 的 REST API 延迟可能更高。
- **影响**：关系图首屏加载 2s 目标可能受影响；PIPL 要求数据尽量在境内存储。
- **对策**：免费层验证阶段可接受；用户反馈延迟明显时 → Pro 计划或迁阿里云 PG，后端同迁阿里云 ECS（一次性切换，数据层已封装好）。

### 5.3 Apple 登录上架要求

- **问题**：App Store 审核要求——如果 App 使用了**任何第三方登录**（含微信），则**必须同时提供 Apple 登录**。
- **应对**：Flutter `sign_in_with_apple` 已经包好，只需在 Apple Developer 后台开通 Sign in with Apple 能力即可。此项不增加额外费用。
